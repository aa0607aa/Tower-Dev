# tests/ — 자동 테스트

**PHASE 0 시점에는 테스트 러너가 아직 없다.** 폴더 구조만 잡혀 있다.

러너 선택(GUT 같은 외부 플러그인 vs 자체 `SceneTree` 스크립트)은 **PHASE 1 착수 시 결정**한다.
개발 가이드 §B5에 따라 외부 플러그인은 실제로 시간을 줄일 때만, 오너에게 먼저 알리고 도입한다.

수동 검증 명령은 `docs/TEST_CHECKLIST.md` 하단 참고.

## 먼저 들어올 테스트 (개발 가이드 §13)

- 1층 고정성 — 시드를 바꿔도 지형 동일
- 동적 배치 결정성 — 재로드 시 전리품/유배자/상태 불변
- 경로 보장 — 시드 100~1000개에서 시작점→계단 접근 불가 0건
- **함정 단서 강제** — 치명 함정의 `clues[]`가 비면 실패
- 프레임 독립성 — 30/60/120 FPS에서 이동/타이머 체감 동일
- 정보 비대칭 — 미발견 함정·계단·비밀 누출 없음

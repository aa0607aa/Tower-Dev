## 1. 명칭 · 주인공

- 정식 명칭은 「탑」. UI·코드·주석·커밋 메시지에서 "오르골의 탑"을 쓰지 않는다. (D-001)
- 플레이어는 **랜덤 생성 유배자**. 오르골은 소설 주인공이자 특수 개체이며, 그 예외 규칙(스탯 8/12/14 등)을
  일반 유배자 생성에 자동 적용하지 않는다. (D-002)
- 랜덤 유배자 생성 규칙(출신·초기 스탯 분포·특성·직업 후보)은 **[TBD]** — 임의 확정 금지.

## 2. 1층

- **지형은 고정.** `data/floors/floor1_fixed/`에서 로드하며 시드와 무관하게 항상 동일하다. (D-003)
- 시드가 결정하는 것은 **전리품 · 유배자 스폰 · 상태/활성 플래그**뿐이다.
- 1층에 프로시저럴 지형 생성기를 만들지 않는다. 프로시저럴 기술은 폐기가 아니라 **2층 이후 백로그**.
- 서든데스: 눈을 뜬 뒤 **정확히 3600초**. 발동 후 가장자리부터 사람 걷는 속도로 붕괴하며 **즉사가 아니다**
  → 계단 위치를 알면 탈출 가능. (D-010)
- 1층에는 생명의 샘·마인드맵이 없다. 초기 장비는 전 유배자 공통 **대거(날 30cm+)**. (D-011)
- 1층 "시스템 미작동"의 범위 = 마인드맵 불가 + 2층 이후 탑 보정 미적용.
  상태창·잔여시간·신체능력·상처·장비·전투 자체는 **작동한다**. (D-009)
  "2층 이후 보정"의 세부 목록은 **[TBD]**.
- 1층 핵심 위협은 함정과 고참 유배자. **모든 치명적 함정에는 사전 단서가 필수**이며,
  이는 `TrapData.clues[]`가 비면 실패하는 테스트로 강제한다. (개발 가이드 §7.2, §13)

## 3. 계단

- 계단은 지형이 아니라 **파티별 귀속 특수 시설**이다. `FloorState.party_stairs[]`로 모델링하며
  단일 `stair_id`로 만들지 않는다. (D-004)
- MVP는 파티 1개 기준으로 단순화하되 **스키마는 파티 귀속을 전제로** 잡는다.
- 파티 탈퇴 시 계단 유지 vs 신규 생성 확률/조건, 파티장 변경 처리는 **[TBD]**.
- 특수 시설(계단/생명의 샘/모루)은 NPC에게 기본 투명 + 인식저해. 접촉으로 인식하면 이후 계속 보이나
  이용은 불가. → `NPCData.perceived_facilities[]` (영구)

## 4. 스탯

- 표시 스탯은 **힘(STR) · 민첩(AGI) · 지능(INT) 3종뿐**. 인간 평균 각 10(합 30). (D-005)
- 체력·반사·의지·마력 등은 **내부 파생값(비노출)**이다. 6스탯 잔재를 만들지 않는다.
- v1.0의 "합계 65 vs 30" 충돌은 **폐기(해소됨)**. 다시 꺼내지 않는다.
- 레벨당 스탯 포인트 1, 스탯 3점 투자 단위로 스킬 후보 발생, 하드 캡 없음.
- 파생 능력 목록·계산식, 성장곡선 연속 보간 방식과 최종 수치는 **[TBD]**
  (개발 가이드 §7.5의 기준점 표는 DESIGN이며 튜닝 대상).

## 5. 상태 계층

- `RunState(회차) → WorldState(월드) → FloorState(층)` 3계층. (D-006)
- 회차 ⊃ 여러 월드. 한 회차에 복수 월드가 동시 존재한다.
- MVP가 회차 1 · 월드 1 · 1층만 채우더라도 **3계층 스키마를 미리 잡아둔다.**
- 사망은 회귀가 아니라 **새 회차 진입**(0층 복귀). 초기 스탯과 기억은 유지,
  성장 스탯·스킬·칭호·아이템·현재 세계는 초기화. 유배자 총 수명 100년.
- 0층에서 100년을 전부 소모했을 때의 결과는 **[TBD]**.

## 6. 전투 · 시간

- 반실시간. 턴제가 아니다. 일반 탐색은 실시간, 전술 메뉴는 일시정지 또는 슬로모션.
- **마인드맵을 열면 시뮬레이션 일시정지**하며, 1층에서는 마인드맵을 쓸 수 없다. (D-008)
- 4단계 피해 구조 + **비랜덤 크리티컬** + 무기 수명 채택. 수치는 **[TBD]**. (D-007)
- 크리티컬은 랜덤 %가 아니라 실제 사건(급소 적중·완벽한 기습·특정 스킬·무기 수명 최후 일격)이 만든다.
- 명중/회피, 부위별 급소 배율, 마법 피해/저항, 무기별 스탯 가중치는 전부 **[TBD]**.
- 게임 월드 시간은 프레임이 아니라 별도 **Simulation Clock**이 관리한다.

## 7. AI 개입 경계

- **엔진이 진실의 단일 출처(SSOT).** AI가 출력한 텍스트만으로 HP·아이템·위치·NPC 생존·역사 결과·
  계단 귀속·열매 효과를 바꾸지 않는다.
- AI는 구조화된 Action Proposal만 내고, 엔진이 검증 후 실행한다.
  존재하지 않는 ID·죽은 NPC 부활·임의 아이템 생성·맵/역사/계단 변경은 **거부**한다.
- API 실패 시 NPC는 "응답 실패/재시도" 상태가 되고 **월드 루프는 계속 정상 동작**한다.
- 미발견 함정·계단·비밀이 UI나 AI 대화로 누출되면 안 된다(정보 비대칭 테스트).

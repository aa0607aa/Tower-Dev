# CANON_NOTES.md — 통합됨

> **이 문서의 내용은 `docs/canon/`으로 옮겼다. 여기에 canon을 적지 마라.**

## 왜 비웠나

이 파일은 설정서 원본이 저장소에 없던 동안 임시 canon 메모로 쓰였다.
2026-08-17에 원본(`SETTING_BIBLE_v1.1.docx`)이 들어와 **133개 항목 / 15개 도메인**의
정식 색인 `docs/canon/`을 만들면서 역할이 끝났다.

두 곳에 같은 canon을 두면 반드시 어긋나고, 어긋나는 순간 어느 쪽이 맞는지 아무도 모르게 된다.
그건 이 체계가 막으려던 바로 그 사고다. 그래서 내용을 옮기고 여기는 포인터만 남긴다.
(같은 이유로 `docs/canon/`은 마크다운 단일 소스로 유지하며 JSON 색인을 두지 않는다 —
`docs/canon/README.md` 참고.)

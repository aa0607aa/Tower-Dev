### SKL-003 · 가지의 스탯 노드 3개를 완성하면 스킬이 즉시 개화한다

- **상태**: CANON
- **출처**: 설정서 v1.1 §11.1 · **DECISIONS D-023** (오너 확정 2026-08-19)
- **내용**:
  - 스탯 포인트는 상태창의 STR/AGI/INT 숫자에 직접 배분하지 않고 **마인드맵의 연결된 가지를 따라 투자**한다.
  - 가지 위의 작은 색상 노드는 시스템상 고정된 스탯을 뜻한다.
    - **빨강 = 힘(STR)**
    - **초록 = 민첩(AGI)**
    - **파랑 = 지능(INT)**
  - 색상 노드 **1개를 활성화할 때 스탯 포인트 1을 소비하고 해당 스탯이 정확히 +1** 오른다.
  - 스킬 노드로 이어지는 한 가지 구간의 **스탯 노드 3개를 모두 활성화하면 그 가지에 자동 진입**한다.
  - 세 번째 노드가 채워져 스킬 노드에 도달하는 순간 **별도의 선택 단계 없이 스킬이 즉시 개화**한다.
- **판단**: 설정서의 "스탯 포인트 3점 투자마다 스킬 후보"를 오너가 실제 UI/성장 구조로 구체화했다.
  따라서 단순히 한 스탯 숫자에 3점을 몰아넣는 구조로 구현하면 안 된다. **경로상의 세 노드가 실제 성장 기록**이다.
- **구현**: 연결 그래프 + 노드 활성 상태 · PHASE 6. 임의의 비연결 원거리 노드를 직접 찍을 수 없게 한다.
- **관련**: SKL-006, CHR-002, CHR-006, CHR-020

### SKL-006 · 마인드맵 구조와 랜덤 스킬 개화

- **상태**: CANON(구조) / **TBD**(정확한 깊이·가중치)
- **출처**: 설정서 v1.1 §11.1 · **DECISIONS D-023**
- **내용**: 마인드맵은 **힘·민첩·지능 세 갈래를 기반으로 뻗는 연결형 성장 네트워크**다.
  - 스킬 노드에 도달하면 **어떤 스킬이 개화할지는 랜덤**이다. 플레이어가 여러 완성 후보 중 하나를 골라 확정하는 방식이 아니다.
  - 설정서의 **현재 스탯 배분 80% + 상황·칭호·기존 스킬·소지 장비 20%**는
    개화할 스킬을 뽑기 위한 **후보 풀/가중치 형성 규칙**으로 해석한다.
  - **중심에서 멀리 뻗을수록 좋은 스킬의 등장 가능성이 높아진다.**
  - 동시에 중심에서 멀어질수록 **이미 투자한 스탯과 기존 개화 스킬과의 연관성이 더 강해진다.**
  - 일정한 전문화 깊이를 넘으면 **현재 빌드와 아예 상관없는 스킬은 후보 풀에 들어올 수 없다.**
  - 특정 조건에서만 등장하는 스킬은 계속 존재한다.
  - 스킬이 개화하면 **그 스킬을 기점으로 새로운 가지가 다시 뻗어** 다음 성장을 이어간다.
- **판단**: 초반에는 랜덤성이 빌드의 예상 밖 방향을 만들 수 있지만, 깊게 투자한 뒤에도 완전히 무관한 스킬이
  계속 튀어나오면 장기 투자에 대한 통제감이 사라진다. 오너 확정은 **깊이 자체를 전문화 압력으로 사용**해
  랜덤성과 빌드 정체성을 동시에 유지하는 구조다.
- **구현**: 태그/연관도 기반 weighted pool + 결정적 RNG/결과 저장(`SYS-003`).
  **정확한 전문화 임계 깊이, 연관도 공식, 태그 체계와 가중치는 TBD**이며 임의 확정하지 않는다.
- **관련**: SKL-003, SKL-005, SKL-008, CHR-006, SYS-003

### SKL-007 · 유니크 스킬의 레벨 구간

- **상태**: DESIGN
- **출처**: 설정서 v1.1 §11.5
- **내용**: 획득 난이도의 기준 이미지 —
  - **Lv.700까지는 거의 획득하기 어렵다**
  - **Lv.700~1500 구간은 보유자 기준 1~2개** 정도가 일반적인 상한 이미지
  - **Lv.1500 이후에는 다수 보유자**가 나타날 수 있다
- **판단**: 설정서 §11.5에 있는 숫자지만 원문이 **"일반적인 상한 이미지"**라는 표현을 쓴다.
  확정 수치가 아니라 밸런스 감각을 전달하는 서술이므로 DESIGN이다.
  반면 같은 절의 **"유일성의 범위는 회차 전체"**(`SKL-004`)는 세계의 규칙이라 CANON이다.
  한 절 안에서도 성격이 다른 문장은 갈라 등재한다.
- **구현**: MVP 범위 밖
- **관련**: SKL-004

### SKL-009 · 주요 스킬 예시

- **상태**: CANON
- **출처**: 설정서 v1.1 §11.3
- **내용**: 스킬 설계의 기준 사례.

  | 스킬 | 유형 | 설정 |
  | --- | --- | --- |
  | 점멸 단검 | 액티브 | 생성한 단검 위치로 순간이동. 단검은 스킬 일부라 재생성 가능 |
  | 강격 | 액티브 | 발동 후 1회의 근접 물리 공격을 크게 증폭 |
  | 대시 | 액티브 | 순간적인 스프린트/순수 이동기 |
  | 신속 | 패시브 | 모든 동작 자체에 속도 배율. 중첩 가능하며 과하면 일상 동작까지 빨라짐 |
  | 샤프 슈팅 | 액티브 | 비인지 상태의 사격에 큰 피해·조준 보정 |
  | 은신 | 패시브 | 그림자에 녹아들 듯 인식에서 사라짐. 높은 민첩/지능 격차나 감지 수단 필요 |
- **구현**: `data/skills/` · PHASE 4 이후 (대시는 PHASE 4)
- **관련**: CBT-007, CBT-009

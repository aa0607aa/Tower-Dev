# GOD — 신 · 신좌 · 대신격

신좌 체계와 알려진 신들. 세계 축의 Divine Influence는 [HIS](HIS.md) HIS-004.

---

### GOD-001 · 플레이어도 신이 될 수 있다

- **상태**: CANON
- **출처**: 설정서 v1.1 §20.1
- **내용**: **신좌에 도달한 플레이어가 일반 신이 될 수 있다.**
  신좌 점유자는 **불사 고정**이며 신도에게 가호와 능력을 부여한다.
- **구현**: MVP 범위 밖
- **관련**: GOD-002, WLD-002

### GOD-002 · 신좌는 주로 심연에 있고 전투가 발생할 수 있다

- **상태**: CANON
- **출처**: 설정서 v1.1 §20.1
- **내용**: 신좌 위치는 **주로 심연 안에서 랜덤**하다.
  신좌 도달 시 **기존 점유자와 전투가 발생할 수 있다.**
  회차가 바뀌면 신 구성도 달라진다.
- **구현**: `RunState.gods_thrones[]` · MVP 범위 밖
- **관련**: GOD-001, DGN-002, WLD-002

### GOD-003 · 알려진 신 유형

- **상태**: CANON
- **출처**: 설정서 v1.1 §20.2
- **내용**:

  | 신 | 관련 |
  | --- | --- |
  | 전쟁신 | 오크 종족신 |
  | 혼돈신 | 범종족 · 보라색 |
  | 규율신 | 인간 종족신 |
  | 마법신 | 범종족 |
  | 자연신 | 엘프 종족신 |
  | 결투신 | 범종족 |
  | 그 외 | 회차/성향에 따라 다수 생성 |
- **구현**: `RunState.gods_thrones[]` · MVP 범위 밖
- **관련**: GOD-004, RAC-001

### GOD-004 · 접미사가 신의 성격을 가른다

- **상태**: CANON
- **출처**: 설정서 v1.1 §20.3
- **내용**: 같은 종류의 신이라도 **접미사에 따라 성격·가호·능력이 달라진다.**
  예: "순결" 자연신은 보수적·배타적일 수 있고, 전쟁신의 접미사는 파괴·죽음·야성 등으로 갈린다.
- **구현**: MVP 범위 밖
- **관련**: GOD-003

### GOD-005 · 대신격은 플레이어가 착석할 수 없다

- **상태**: CANON
- **출처**: 설정서 v1.1 §20.4
- **내용**: 대신격은 **플레이어 착석 불가**이며 **탑 시스템에 깊게 개입**한다.
  매우 희귀하고 **만신전에 동상이 없으며 소통이 불가능**하다.
  알려진 대신격: **시간의 신 / 심연의 신 / 행운의 신.**
- **구현**: MVP 범위 밖
- **관련**: GOD-001, FAC-008, HIS-004

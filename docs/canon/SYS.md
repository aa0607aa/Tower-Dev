# SYS — 메타 규칙

세계 안의 사실이 아니라 **이 게임을 만드는 방식**에 대한 규칙. AI 개입 경계, 결정성, 정보 비대칭,
데이터 정책. 어겼을 때 세계관이 아니라 **프로젝트가 망가지는** 항목들이다.

---

### SYS-001 · 게임 엔진이 진실의 단일 출처(SSOT)

- **상태**: CANON
- **출처**: 설정서 v1.1 · 개발 가이드 §4 · COLLABORATION_PROTOCOL §1
- **내용**: 게임 엔진이 진실의 단일 출처다. **AI가 출력한 텍스트만으로** HP·아이템·위치·NPC 생존·
  역사 결과·계단 귀속·열매 효과를 바꾸지 않는다.
- **구현**: 전 PHASE · TEST_CHECKLIST G-5
- **관련**: SYS-002, SYS-006

### SYS-002 · AI는 GameState를 직접 수정하지 않는다

- **상태**: CANON
- **출처**: 개발 가이드 §10 · COLLABORATION_PROTOCOL §1
- **내용**: AI는 **구조화된 Action Proposal**만 반환하고, 엔진이 검증한 뒤에 실행한다.
  거부해야 하는 것: 존재하지 않는 ID, 죽은 NPC 부활, 임의 아이템 생성, 맵·역사·계단 변경.
- **구현**: `scripts/ai/` + Validator · PHASE 9 · TEST_CHECKLIST G-5
- **관련**: SYS-001, SYS-006

### SYS-003 · 모든 랜덤은 시드 또는 결과를 저장한다

- **상태**: CANON
- **출처**: 개발 가이드 §4 · §13
- **내용**: 모든 랜덤 생성은 시드 또는 생성 결과를 저장해 **재로드 시 동일하게 복원**된다.
  플레이어가 보지 않았다고 해서 다시 생성되지 않는다.
  전역 `randi()`를 게임 로직에 쓰지 않는다.
- **구현**: `RandomNumberGenerator` + 시드 보관 · TEST_CHECKLIST G-4
- **관련**: FLR-002, SYS-007, SYS-009

### SYS-004 · 시각 오브젝트와 데이터 객체를 분리한다

- **상태**: CANON
- **출처**: 개발 가이드 §4
- **내용**: 스프라이트가 화면에서 사라져도 **데이터가 삭제된 것이 아니다.**
  노드는 데이터를 소유하지 않고 표시만 한다. 또한 한 시스템이 다른 시스템의 내부 데이터를 직접
  수정하지 않고 이벤트·서비스 계층을 거친다.
- **구현**: 전 PHASE · `docs/CODING_STYLE.md` §3
- **관련**: SYS-001

### SYS-005 · 정보 비대칭 — 미발견 정보는 누출되지 않는다

- **상태**: CANON
- **출처**: 개발 가이드 §13
- **내용**: 아직 발견하지 않은 함정·계단·비밀이 **UI나 AI 대화로 누출되면 안 된다.**
  AI에게 넘기는 컨텍스트에도 플레이어가 모르는 정보를 넣지 않는다.
- **구현**: 컨텍스트 빌더 · PHASE 9 · TEST_CHECKLIST G-2
- **관련**: FAC-003, FLR-011, SYS-009

### SYS-006 · AI는 이미 생성된 것을 바꾸지 않는다

- **상태**: CANON
- **출처**: 설정서 v1.1 · 개발 가이드 §3.1, §10
- **내용**: AI/GM은 이미 생성된 맵·난이도·계단·아이템·역사 결과·열매 효과를 임의로 바꾸지 않는다.
  미래는 인과 그래프의 **합법적 분기로만** 바뀌며, "스토리가 재밌어 보인다"는 이유로 교체하지 않는다.
- **구현**: Validator · PHASE 9
- **관련**: SYS-002, WLD-008, WLD-009

### SYS-007 · AI가 꺼져도 게임은 동작한다

- **상태**: CANON
- **출처**: 설정서 v1.1 · 개발 가이드 §3.1, §10
- **내용**: 이동·전투·파밍·함정·시간·서든데스·1층 로드·세이브는 **AI 호출 없이** 동작해야 한다.
  API 실패 시 NPC는 "응답 실패/재시도" 상태가 되고 **월드 루프는 계속 정상 동작**한다.
- **구현**: AI Bridge를 게임 루프와 완전 분리 · TEST_CHECKLIST G-1
- **관련**: SYS-002

### SYS-012 · 레거시 텍스트 RPG 규칙은 canon에서 제거됐다

- **상태**: CANON
- **출처**: 설정서 v1.1 §0.4
- **내용**: 과거 텍스트 시뮬레이션에서 쓰던 **"선택지 제시 금지", "GM이 묘사만 한다",

  옛 대화 로그나 v1.0 이전 문서에서 이런 규칙을 발견해도 따르지 않는다.
- **구현**: 전 PHASE
- **관련**: SYS-001, SYS-002

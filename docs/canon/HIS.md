# HIS — 역사 · 인과 그래프 · 세계 축

월드의 과거·현재·미래가 어떻게 연결되는가. 월드 자체의 정의는 [WLD](WLD.md).

---

### HIS-001 · 회차 시작 시 전체 구조는 이미 설계되어 있다

- **상태**: CANON
- **출처**: 설정서 v1.1 §5.1
- **내용**: 게임/세계가 시작될 때 각 월드의 튜토리얼층부터 왕국의 문까지 전체 구조가 이미
  설계되어 있어야 한다. 단 **"미래의 결과 하나를 고정한다"는 뜻이 아니다.**
  선결정하는 것은 층 슬롯·장소·핵심 사건·분기 조건·대체 보스/지형/세력 버전과 인과 연결이다.
- **구현**: `WorldState` 생성 시점 · MVP 범위 밖
- **관련**: HIS-002, WLD-003, SYS-003

### HIS-002 · 미래는 고정값이 아니라 인과의 결과

- **상태**: CANON
- **출처**: 설정서 v1.1 §5.2
- **내용**: 과거의 전쟁·왕의 생존·종족의 멸망·기술의 발견 같은 핵심 사건은 후대의 층과 연결된다.
  플레이어가 과거에 개입하면 다음 층의 보스·지형·세력·문명 수준이 바뀔 수 있다.
  **미래층은 "미래라는 테마"가 아니라 해당 월드가 실제로 도달한 미래 상태다.**
  같은 시작점에서 초고도 문명이 될 수도, 잿더미 아포칼립스가 될 수도 있다.
- **구현**: Event Node 활성 결과 갱신 · MVP 범위 밖
- **관련**: HIS-003, HIS-004, SYS-006

### HIS-003 · Event Node 데이터 원칙

- **상태**: DESIGN
- **출처**: 설정서 v1.1 §5.5
- **내용**: 핵심 사건은 Event Node로 만들고 **기본 결과 · 분기 조건 · 영향 대상 ·
  연결된 미래층/보스/팩션**을 가진다. 활성 결과는 플레이 중 사건이 확정될 때 갱신한다.
  **과거 층을 다시 쓴다고 전체 월드를 무작위 재생성해서는 안 된다.**
- **판단**: **설정서 §5.5가 스스로 `DESIGN` 태그를 달고 있어** 그대로 따랐다.
  즉 이 상태는 내 해석이 아니라 원문의 분류다. Event Node의 필드 구성은 바뀔 수 있다.
  다만 마지막 문장(무작위 재생성 금지)은 `SYS-003` 결정성과 같은 내용이라 실질적으로 CANON이며,
  구현에서 이 한 줄만은 협상 대상이 아니다.
- **구현**: `WorldState.causal_graph` · MVP 범위 밖
- **관련**: HIS-002, SYS-003

### HIS-004 · 세계 4축

- **상태**: CANON(개념) / **TBD**(수치)
- **출처**: 설정서 v1.1 §5.3
- **내용**: 각 월드는 아래 축을 **독립적으로** 가진다. 한 축이 높다고 다른 축이 자동으로 낮아지지 않는다.

  | 축 | 의미 |
  | --- | --- |
  | Technology | 산업·과학·기계·정보기술 등 실용 기술의 발전 수준 |
  | Magic | 마법 연구와 운용의 사회적·기술적 발전 수준 |
  | Religion | 사회가 신앙·교단·의례에 의존하는 정도 |
  | Divine Influence | 신·사도·가호·신권 세력이 현실 정치/전쟁/생활에 미치는 힘 |
- **판단**: 축의 **이름과 독립성**은 설정서 §5.3이 확정했으므로 CANON이고,
  값의 범위·눈금·초기 분포는 원문에 없어 TBD다. 특히 **"한 축이 높다고 다른 축이 자동으로
  낮아지지 않는다"**를 CANON으로 못 박은 이유는, 구현할 때 4축을 합이 일정한 배분값
  (예: 총합 100 분배)으로 만들기 쉬운데 그러면 이 문장을 정면으로 위반하기 때문이다.
  **각 축은 서로 독립된 값이어야 한다.**
- **구현**: `WorldState.axes` — 독립 스칼라 4개 · MVP 범위 밖
- **관련**: HIS-005, GOD-005, WLD-009(통합됨)

### HIS-005 · 기술과 신앙의 경향 (절대 법칙 아님)

- **상태**: CANON
- **출처**: 설정서 v1.1 §5.4, §20.5
- **내용**: 기술이 발전할수록 유배자·NPC가 신보다 기술에 의지하는 경향이 강해지고, 일반적으로
  신권 세력의 영향력이 감소하는 **방향성**이 있다. **그러나 절대 법칙이 아니다** —
  초고도 기술문명이면서 신의 권세가 매우 강한 세계도 생성될 수 있다.
  기술로 종족적 약점을 해결해 미래의 패권 종족이 바뀌는 경우도 가능하다.
- **구현**: 인과 그래프 + 세계 축으로 생성 · MVP 범위 밖
- **관련**: HIS-004, GOD-005, RAC-001

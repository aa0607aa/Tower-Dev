# 초기 Path of Exile 패시브 트리 참고 메모

> **성격: REFERENCE / DESIGN 참고용. Canon 아님.**
>
> 오너 요청에 따라 최신 Path of Exile이 아니라 **2011~2013 Closed Beta / Open Beta 초창기 패시브 트리**를
> 「탑」 마인드맵의 시각·경로 설계 참고 대상으로 본다. PoE의 게임 규칙을 그대로 가져오지 않는다.

## 확인한 초기 PoE 특징

공식 Path of Exile 포럼의 당시 개발자/FAQ 기록에서 확인되는 핵심은 다음과 같다.

- 패시브 트리는 **하나의 거대한 연결 네트워크**이며, 포인트는 현재 활성 경로에 연결된 노드에만 투자한다.
- 노드 하나에 여러 포인트를 몰아넣는 방식보다 **한 노드에 1포인트를 쓰고 다음 노드로 이동**하는 구조를 의도했다.
- 단순 능력치 노드가 긴 경로의 **road / highway** 역할을 하고, 무기·공격·방어·원소 등 관련 효과가 모인
  **cluster**가 목적지/지역 역할을 했다.
- 초반에는 선택지를 과도하게 열지 않고 적은 분기에서 시작해, 진행할수록 선택지가 빠르게 늘어나는 형태를 사용했다.
- 먼 계열로 넘어가는 것은 가능하되 더 많은 경로 포인트가 필요하도록 **기회비용**을 두었다.
- 2012년에는 개발팀이 패시브 트리 자체의 설계 고려사항을 별도 개발 영상으로 설명했고,
  당시 유저들도 긴 연결 경로를 `highway`라고 부르는 구조를 인지하고 있었다.

## 「탑」과 닮은 점

초기 PoE를 참고하기 좋은 부분은 **개별 스킬 내용**보다 그래프의 읽는 법이다.

1. **작은 성장 노드가 길을 만든다.**
   - PoE: 작은 속성 노드가 주요 패시브 클러스터 사이의 road/highway 역할.
   - 탑: 빨강/초록/파랑 스탯 노드가 스킬 개화점까지 가는 실제 경로 역할.

2. **경로 선택 자체가 빌드다.**
   - 원하는 큰 노드 하나만 바로 찍는 것이 아니라 그곳까지 가는 동안 다른 노드를 반드시 거친다.

3. **멀리 갈수록 전문화가 선명해진다.**
   - 초기에는 선택 폭이 비교적 넓고, 특정 방향으로 멀리 투자할수록 이미 선택한 성장 방향의 영향이 커진다.

4. **작은 노드와 큰 랜드마크를 시각적으로 구분하기 좋다.**
   - 탑에서는 작은 색 점 = 스탯, 큰 노드 = 스킬 개화점으로 시각 계층을 명확히 할 수 있다.

## 「탑」이 PoE와 다른 핵심

여기는 **의도적으로 다르게 유지한다.**

- 초기 PoE의 트리 토폴로지와 노드 효과는 기본적으로 **고정된 거대 그래프**다.
- 「탑」은 스킬 개화 결과가 **랜덤**이며, 개화한 스킬에서 다음 가지의 성격이 이어서 만들어진다.
- PoE의 트리 노드는 주로 패시브 효과지만, 「탑」의 큰 노드는 **실제 스킬 개화**다.
- 「탑」은 색상 노드가 직접 STR/AGI/INT를 +1시키며, 숫자창에서 스탯을 직접 배분하지 않는다.
- 「탑」은 기본적으로 임의 respec을 허용하지 않는다. 종족 변경으로 새 종족 기준에 맞지 않는
  스킬/하위 가지가 취소될 때만 해당 구간의 투자 포인트가 환원된다 (`D-023`).

## 가져올 만한 시각/UX 원칙

- 작은 스탯 노드는 **길**, 스킬 개화점은 **랜드마크**로 크기/형태를 확실히 다르게 한다.
- 중심부는 읽기 쉬운 적은 분기에서 시작하고, 바깥으로 갈수록 가지 수와 전문화가 늘어나게 한다.
- 이미 진행 가능한 다음 노드만 강조해 "거대한 그림은 복잡하지만 실제 조작은 단순"하게 만든다.
- 긴 이동 가지와 전문 스킬 군집의 시각 문법을 분리해, 플레이어가 멀리서도 빌드의 흐름을 읽을 수 있게 한다.

이 문서는 **초기 PoE에서 배울 UX/그래프 구성 원리만 정리한 것**이다.
「탑」의 랜덤 개화·색상 스탯·종족 변경 환원 규칙의 직접 근거는 `D-023`과 `SKL/RAC` Canon이다.

# 1층 소설 초반 원문 참고 메모

> **성격: REFERENCE / DESIGN 근거용.**
> 2026-08-19 오너가 제공한 소설 초반 캡처를 요약한 문서다.
> 설정서 v1.1이나 `DECISIONS.md`를 자동으로 덮어쓰지 않는다. 소설 원문과 현재 게임 Canon이 다르면
> 임의로 합치지 말고 `[CANON CONFLICT]`로 올린다.

## 목적

PHASE 2 `P2-T2`의 1층 greybox에서 **실제 크기·방/공간 수·동선 복잡도**를 잡을 때 참고한다.
현재 설정서 v1.1에는 1층의 정확한 가로세로 크기나 방 개수가 숫자로 정해져 있지 않다.
이번 소설 캡처에도 정확한 미터/타일/방 수는 나오지 않는다.

## 캡처에서 확인되는 1층 공간 단서

1. 1층은 반복해서 **미로**로 묘사되며, 고대 사원풍의 회랑·장식벽·천장이 없는 구조다.
2. 지형과 함정은 반복 죽음을 통해 외울 수 있을 정도로 안정적이며, 숙련자는 매복 위치와 위험지점을 기억한다.
3. 함정은 도처에 있고, 다른 유배자와 고참 유배자가 실제 공간을 함께 이용하므로
   단순 직선 통로 하나가 아니라 **여러 우회·매복·파밍 선택지가 있는 구조**여야 한다.
4. 1층 서든데스는 1시간이며 가장자리부터 붕괴한다. 과거 게임 시절에는 서든데스 직전까지
   파밍하는 것이 정석이었다는 서술이 있다. 따라서 1시간은 순수 이동 시간이 아니라
   **탐색 + 함정 확인 + 전투 + 루팅 + 욕심을 얼마나 더 낼지**를 포함한 플레이 예산으로 보는 편이 맞다.
5. 동시에 원문은 1층을 **복잡할 것도 없고 난관도 적은 층**, 게임 시절에는
   **조작법 튜토리얼에 가까운 저난이도 스테이지**로 묘사한다.
   → 1층의 어려움은 길찾기 퍼즐 자체보다 함정·인간·판단 실수에서 와야 한다.
6. 미로의 **초반은 대체로 공평하다**는 서술이 있다. 시작 직후부터 피할 수 없는 살육 구간으로 만들기보다
   초반은 기본 조작/관찰을 할 여지를 주고, 이후 위험 밀도를 올리는 구조가 원문 감각과 맞는다.
7. 한 장면에서는 계단이 **미로의 중심 근방**에 존재한다. 이것은 그 장면의 실제 배치 단서로는 쓸 수 있지만
   현재 `D-016/FAC-012`의 파티별 계단 계산을 폐기하는 일반 규칙으로 확대하지 않는다.
8. 총기는 극저확률이고 일반적인 투사무기는 활/슬링샷~석궁 수준이라는 묘사는 현재 Canon과 대체로 정합한다.
9. 1층 스폰 무기는 대체로 **질이 나쁘지만 초기 대거보다는 낫다.** 이 비교 규칙은 2026-08-19 오너가
   소설 원문을 따르기로 확정해 `D-020/FLR-014`로 Canon에 복원했다.

## 1층 크기/방 수에 대한 결론

### Canon으로 확정할 수 있는 숫자

**없다.**

설정서와 이번 원문 모두 `가로 N m`, `N×N 타일`, `방 N개` 같은 값을 주지 않는다.
따라서 숫자를 원문에서 복원했다고 주장하면 안 된다.

### 원문이 요구하는 설계 성격

- 전체 지형을 여러 회차에 걸쳐 **외울 수 있을 정도로 유한하고 반복 가능**해야 한다.
- 1층답게 **구조 자체는 지나치게 복잡하지 않아야** 한다.
- 하지만 파밍 지점·함정·매복·다른 유배자 때문에 **경로 선택은 충분히 존재**해야 한다.
- 숙련자는 빠르게 핵심 동선을 탈 수 있어야 하고, 뉴비는 같은 공간에서도 함정/사람 때문에 오래 걸리거나 죽는다.
- 60분을 지형 크기만으로 억지로 채우지 않는다. 60분은 위험을 감수하며 파밍을 더 할지 결정하는 상한이다.

## P2-T2 greybox 시작 기준 — APPROVED DESIGN, Canon 숫자 아님

오너가 2026-08-19 `D-019`로 첫 플레이 가능한 회색박스의 **시작 범위**를 승인했다.
최종 맵 크기를 Canon으로 고정한 것이 아니라, Claude가 `P2-T2` 작업을 시작할 수 있게 하는 PLAYTEST용 기준선이다.

- **긴 축 160~220 타일 정도**의 불규칙 미로 영역
- **주요 공간 14~20개**: 큰 방/뜰/회랑 교차점/제단 공간처럼 플레이 판단이 달라지는 단위
- 여기에 **소형 파밍 포켓·막다른 길 6~10개**를 별도 부속 공간으로 둔다
- 일방향 정답길보다 **3~5개의 큰 루프**와 여러 짧은 우회를 둔다
- 민첩 10 기준으로 전투·루팅·함정 확인 없이 핵심 경로만 숙련 주행하면 수 분대,
  여러 분기를 실제로 파밍하면 훨씬 길어지도록 한다

`FLR-015`의 지형 암기 성장과 이번 소설의 저난이도/파밍/매복 묘사를 동시에 만족하는지
`P2-T7` 오너 PLAYTEST로 검증하며, 체감이 다르면 크기/공간 수는 DESIGN 범위에서 조정한다.


**2026-08-19 오너 결정: B, 소설 원문 규칙을 따른다.**

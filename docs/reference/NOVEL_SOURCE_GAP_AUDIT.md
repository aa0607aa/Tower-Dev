# 소설 원작 근거 누락 감사 — Novel Source Gap Audit

> **성격: REFERENCE / SOURCE AUDIT. Canon 자체가 아니다.**
>
> 2026-08-19 오너가 대화에 첨부한 소설 초반 발췌들을 현재 `SETTING_BIBLE_v1.1`,
> `DECISIONS.md`, `docs/canon/`, 구현 문서와 역방향 대조한 결과다.
> 이 문서의 `GAP`은 "원작에 근거가 있으나 현재 통합 설정/색인에 직접 걸리지 않았다"는 뜻이지,
> 자동으로 게임 Canon에 추가한다는 뜻이 아니다. 일반 규칙으로 승격할 때는 오너 승인 또는
> `[CANON CONFLICT]` 절차를 거친다.

|---|---|

## 상세 감사

### NSG-001 · 랜덤 인카운터는 완전 무작위가 아니라 "고정 골격 + 세부 랜덤"

- **상태**: **GAP**
- **원작 발췌**: `3740cb42-6918-4a16-a775-2d1bc709d97f.png`
- **원작 의미**:
  - 인카운터의 **출현 여부**는 랜덤.
  - 일단 출현하면 **기본 토대가 되는 시나리오**를 따른다.
  - 작은 변수와 세부 상황만 랜덤으로 정해진다.
- **현재 반영**:
  - `KGD-004`에는 "두 적대 팩션 중 하나가 제거되어야 계단이 열리는 랜덤 인카운터"라는
    **특정 사례**는 존재한다.
  - 그러나 모든 랜덤 인카운터를 구성하는 일반 원칙으로서
    `authored scenario template + randomized details`는 현재 색인에 없다.
- **누락 의미**:
  - 향후 이벤트 생성기를 "모든 사건을 절차적으로 즉석 생성"으로 잘못 구현하는 것을 막아준다.
- **권고**:
  - 오너 승인 시 `SYS/HIS/KGD` 중 적합한 위치에 **인카운터 생성 원칙**으로 추가.
  - 구현 구조 후보: `EncounterTemplate → eligibility/appearance roll → fixed beats → randomized slots → result save`.
- **자동 Canon화**: 금지. 원작 문장을 게임 전체 인카운터에 적용할지 오너 확인 필요.

### NSG-002 · 2층 요정 마을 vs 적대 팩션, 한쪽 소탕 시 계단 개방

- **상태**: **PARTIAL / 핵심은 MATCHED**
- **원작 발췌**: `b8a2a5a9-c065-46c7-b18f-1b7d21234f39.png`
- **원작 의미**:
  - 숲 인카운터에서 요정 마을이 등장.
  - 요정 적대 세력이 존재하며, 발췌에서는 가능한 적대 세력 풀 중 하나가 정해지는 식으로 묘사.
  - **둘 중 한쪽이 소탕되어야 다음 층 계단이 열린다.**
  - 적대 팩션 정체에 따라 난도가 크게 달라질 수 있다.
- **현재 반영**:
  - `KGD-004`가 "서로 적대하는 두 팩션 중 하나가 제거되어야 계단이 열리는 랜덤 인카운터"를
    이미 CANON으로 보존한다.
- **남은 차이**:
  - 요정 마을, 특정 적대 세력 풀/개수, 2층 특정 사례라는 디테일은 현재 색인에 없음.
- **권고**:
  - 일반 규칙은 `KGD-004`로 충분.
  - 요정/적대 세력 조합은 **2층 authored encounter example**로 별도 source note에 보존하고,
    실제 2층 설계 때 원문 전체 문맥을 다시 확인.

### NSG-003 · 물리적으로 가능한 함정은 돌 같은 외부 물체로도 발동 가능

- **상태**: **GAP — PHASE 3 관련**
- **원작 발췌**: `fe4eb4d4-82ad-45b2-a29d-ba92eda83c6c.png`
- **원작 의미**:
  - 돌을 주워 던져 벽 화살 함정을 의도적으로 발동시킨다.
  - 화살은 발사 후 벽에 부딪혀 파손되고, 이를 통해 위험을 제거한다.
- **현재 반영**:
  - `FLR-011`: 치명 함정에는 사전 단서 필요.
  - `FLR-012`: 발사형 함정은 한 번 소모되면 재충전되지 않음.
  - 하지만 **트리거가 플레이어 몸에만 반응하는지, 투척물/물체도 반응하는지**는 Canon에 없음.
- **누락 위험**:
  - 구현 편의로 `Area2D`를 Player 전용 충돌층에만 연결하면 원작의 대표적 지식 공략이 불가능해질 수 있다.
- **권고**:
  - 일반화는 "모든 함정은 모든 물체에 반응"이 아니라,
    **함정의 물리 메커니즘상 가능하다면 플레이어 외 물체/환경 상호작용으로도 발동·해제할 수 있다** 정도가 안전하다.
  - PHASE 3 trap trigger 설계 전에 오너 확인 권장.

  - 정확한 범위는 확인 필요: 탑 전체인지, 튜토리얼 미궁인지, 유배자에게만 적용되는지, 일반 NPC까지 포함하는지.

### NSG-005 · 미궁의 생물/NPC는 경험을 통해 학습한다

- **상태**: **PARTIAL**
- **원작 발췌**: `ee5929a8-818b-4728-a0a5-2fe17a64b0d6.png`, `dfb79912-a8bc-47a2-9117-a4ee1923814f.png`
- **원작 의미**:
  - 훈련된 인물이 1층 함정을 빠르게 알아보고 대응한다.
  - "미궁의 모든 생물은 경험한다. 인간도 경험한다"는 서술이 있다.
- **현재 반영**:
  - `NPC-001`: NPC는 지식과 과거를 가진 삶의 주체.
  - `NPC-003`: 정보/경험은 생존자와 소문을 통해 퍼질 수 있음.
  - 그러나 **개별 NPC가 실제 경험을 축적해 위험 인식/행동을 개선한다**는 일반 규칙은 명시적이지 않다.
- **권고**:
  - PHASE 7 NPC 기억/학습 구조 설계 전에 검토.
  - 단순 AI 난이도 보정이 아니라 `observed hazard / survived event / learned clue` 같은
    지식 상태가 행동에 영향을 주는 방향이 원작과 맞는다.

### NSG-006 · NPC 배경 정보는 자동 공개되지 않고 대화/관찰로 추론한다

- **상태**: **PARTIAL**
- **원작 발췌**: `fe4eb4d4-82ad-45b2-a29d-ba92eda83c6c.png`, `e485e3e0-c9c8-4c31-9d6f-5aa7c4599b97.png`
- **원작 의미**:
  - 랜덤 NPC는 개연성을 위해 배경 설정을 갖는다.
  - 게임 UI에서는 마우스오버 등으로 만능 상태창처럼 볼 수 있었던 정보를,
    현재 서사에서는 대화와 관찰로 유추한다는 대비가 있다.
  - 일부 고정 NPC는 반복적으로 특정 기본 역할/배경을 가진다.
- **현재 반영**:
  - `NPC-001`: 과거·목표·말투·관계·지식·비밀.
  - `NPC-002`: 고정 NPC/일반 NPC 구분.
  - `SYS-005`: 미발견 정보 UI/AI 누출 금지.
- **빠진 뉘앙스**:
  - **NPC의 상세 배경/능력을 전지적 UI로 직접 열람하지 않는다**는 NPC 정보 노출 규칙은 명시되어 있지 않다.
- **권고**:
  - NPC UI 설계 시 `SYS-005`의 구체 사례로 연결.
  - 고정 NPC의 "기본 역할은 반복되지만 회차 관계 기억은 초기화"는 `NPC-002`와 정합.

### NSG-008 · 유배자의 대다수는 왕국의 문에도 도달하지 못한다

- **상태**: **GAP / 수치 승격 주의**
- **원작 발췌**: `3d5dfce2-7d06-475c-a174-e9fae40c056c.png`
- **원작 의미**:
  - "유배자의 70% 이상이 왕국의 문을 두드린 적도 없다"는 서술.
  - 서든데스가 없다면 특정 층에서 오래 버티는 것이 가능하며,
    상당수는 왕국 공략보다 중간층 생존을 택하거나 거기서 생을 보낸다는 세계 인식.
- **현재 반영**:

  - `70% 이상`이라는 규모감/비율은 현재 색인에 없음.
- **권고**:
  - 원작의 핵심 세계 규모감은 "왕국에 도달하지 못하는 유배자가 대다수" 정도로 Canon 후보.
  - **70%를 하드 수치로 고정할지는 별도 오너 결정** 권장. 플레이 인구/시뮬레이션 밸런스에 영향을 준다.

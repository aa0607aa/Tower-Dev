# 소설 원작 근거 누락 감사 — Novel Source Gap Audit

> **성격: REFERENCE / SOURCE AUDIT. Canon 자체가 아니다.**
>
> 오너가 제공한 소설 원문 발췌를 `SETTING_BIBLE_v1.1`, `DECISIONS.md`, `docs/canon/`과 역대조한다.
> `GAP`은 원작 근거가 있으나 현재 Canon에 직접 걸리지 않았다는 뜻일 뿐 자동 Canon 승격을 뜻하지 않는다.
> 오너가 일반 규칙으로 확정한 항목은 `RESOLVED`로 바꾸고 실제 Canon ID를 연결한다.

## 상태 분류

| 상태 | 의미 |
|---|---|
| **MATCHED** | 현재 Canon/Decision에 핵심 의미가 이미 반영됨 |
| **PARTIAL** | 큰 개념은 반영됐지만 중요한 세부/뉘앙스가 남음 |
| **GAP** | 현재 Canon에서 직접 대응 항목을 찾지 못함 |
| **RESOLVED** | 오너가 일반 규칙으로 확정했고 Canon/Decision에 반영 완료 |
| **SCENE-ONLY** | 특정 장면·인물·회차 사례라 일반 규칙으로 확대 금지 |

---

- `NSG-013/014` 등 PARTIAL 항목은 구현 시 참고하되 자동 승격 금지.

D-024로 기존 핵심 GAP인 **NSG-001/003/004/005/006/008은 모두 해결됨**.

## 상세 감사

### NSG-001 · 랜덤 인카운터는 "저작된 골격 + 세부 랜덤"

- **상태**: **RESOLVED → `SYS-016`, `D-024`**
- **원작 의미**: 출현 여부는 랜덤이지만, 출현한 인카운터는 기본 시나리오 골격을 따르고 허용된 세부만 랜덤화된다.
- **오너 확정**: 이 철학을 일반 인카운터 생성 원칙으로 사용한다.
- **구현 방향**: `EncounterTemplate → eligibility/appearance roll → fixed beats → randomized slots → resolved result save`.

### NSG-002 · 2층 요정 마을 vs 적대 팩션, 한쪽 소탕 시 계단 개방

- **상태**: **PARTIAL / 핵심 MATCHED → `KGD-004`**
- **원작 의미**: 요정 마을과 적대 세력이 공존하고 둘 중 한쪽이 소탕되어야 계단이 열린다. 적대 세력 정체에 따라 난도가 변한다.
- **현재 반영**: `KGD-004`가 "두 적대 팩션 중 하나가 제거되어야 계단 개방"을 일반 사례로 보존.
- **남은 부분**: 요정 마을·구체 적대 세력 풀은 2층 authored encounter 예시로만 보존한다.

### NSG-003 · 물리적으로 가능한 함정은 외부 물체로도 발동 가능

- **상태**: **RESOLVED → `FLR-028`, `D-024`**
- **원작 의미**: 돌을 던져 벽 화살 함정을 먼저 발동·소모한다.
- **오너 확정**: 모든 물리 현상을 정상 구현한다는 원칙. 함정의 메커니즘상 돌·투척물·환경 변화가 트리거를 건드릴 수 있으면 실제로 작동한다.
- **주의**: 모든 함정이 모든 물체에 반응한다는 뜻은 아니다. 압력·접촉·생체·마법 감지 등 실제 정의를 따른다.
- **PHASE 3 영향**: Player 전용 collision trigger 하드코딩 금지.

### NSG-004 · 미궁 언어 통합과 바벨탑

- **상태**: **RESOLVED → `WLD-011`, `D-024`**
- **원작 의미**: 서로 다른 언어권 출신도 미궁에서는 의사소통이 가능하다.
- **오너 확정**: 언어 통합 기능은 존재하며 이를 담당하는 구조물의 이름은 **「바벨탑」**이다.
- **TBD**: 바벨탑의 정확한 위치·외형·규모·작동 메커니즘.

### NSG-005 · NPC/생물은 경험을 통해 학습한다

- **상태**: **RESOLVED → `NPC-006`, `D-024`**
- **원작 의미**: 미궁의 생물과 인간은 경험한다. 훈련/경험으로 함정·위험을 더 잘 알아볼 수 있다.
- **오너 확정**: 개체는 직접 경험하거나 합법적인 정보 경로로 전달받은 내용을 축적하고 이후 행동에 반영한다.
- **주의**: 플레이어 실력에 맞춘 전지적 AI 보정이 아니다.

### NSG-006 · NPC 상세 정보는 자동 UI가 아니라 대화·관찰로 파악

- **상태**: **RESOLVED → `NPC-007`, `D-024`**
- **원작 의미**: 과거 게임 UI에서는 마우스오버로 알던 배경/상태를 소설 속 현실에서는 대화와 관찰로 추론한다.
- **오너 확정**: 게임도 **원작 속 게임 UI보다 소설 속 실제 세계 체험에 가까운 방향**을 택한다.
- **규칙**: NPC의 미발견 배경·능력·성향·지식은 전지적 UI로 자동 공개하지 않는다. 대화·관찰·행동 결과·소문/정보로 알아낸다.

### NSG-007 · 1층 핵심 공간/위협/반복 학습

- **상태**: **MATCHED**
- **현재 반영**: `FLR-001`, `FLR-010~015`, `docs/reference/FLOOR1_NOVEL_SOURCE_NOTES.md`.
- **핵심**: 고대 사원풍 고정 미로, 함정·고참 유배자, 반복 죽음을 통한 지도/위험지점 학습.

### NSG-008 · 왕국의 문에도 도달하지 못하는 유배자가 대다수

- **상태**: **RESOLVED → `WLD-012`, `D-024`**
- **원작 표현**: "70% 이상".
- **오너 확정**: **70%는 고정 통계가 아니다.** 일반 유배자 수준과 튜토리얼 난이도를 조절할 때 "왕국에 도달하지 못하는 유배자가 대다수"라는 체감을 유지하는 DESIGN 기준이다.
- **금지**: `0.70` 같은 하드 상수로 세계 규칙을 고정하지 않는다.

### NSG-009 · 정보는 미궁에서 가장 중요한 자산 중 하나

- **상태**: **MATCHED**
- **현재 반영**: 설정서 §1.1, `CHR-012`, `SYS-005`, `NPC-003`, `FAC-010`.
- **조치**: 별도 Canon 추가 불필요. 소설 source 근거로 활용.

### NSG-010 · 1층 스폰 장비는 저품질이어도 초기 대거보다 대체로 낫다

- **상태**: **MATCHED / 이미 D-020으로 해결**
- **현재 반영**: `FLR-014`, `D-020`, 1층 loot 데이터.

### NSG-011 · 1층은 저난도 튜토리얼이지만 방심/욕심/정보 부족으로 죽는다

- **상태**: **MATCHED / DESIGN 참고**
- **현재 반영**: `FLOOR1_NOVEL_SOURCE_NOTES.md`, `FLR-011`, `DGN-004`, D-019 greybox 기준.
- **의미**: 길찾기 자체를 과도하게 어렵게 하기보다 함정·인간·파밍 욕심·판단 실패가 사망 원인이 된다.

### NSG-012 · 1층 인간 사냥과 뉴비 구조/영입 모두 실리적 선택

### NSG-013 · 총기/샷건은 극희귀하지만 큰 초반 우위가 될 수 있다

- **상태**: **PARTIAL / 장면 예시**
- **현재 반영**: `FLR-014`에 일반 투사무기 상한·총기 극저확률.
- **주의**: 특정 샷건의 몇 층간 "치트급" 체감은 장면/아이템 사례이므로 자동 일반화 금지.

### NSG-014 · 서든데스는 무한 파밍/정착을 끊고 전진시킨다

- **의미**: 서든데스는 단순 타이머가 아니라 한 층에 영구 정착·무한 파밍하는 행동을 끊는 구조적 압력.

### NSG-017 · 시스템 열매나무는 소규모 몬스터 집단 주변에 자주 스폰된다

- **상태**: **RESOLVED → `ITM-007`, `D-025`** (오너 승인 2026-08-20)
- **원작 발췌**: 2026-08-19 15:09 업로드 캡처.
- **원작 의미**:
  - 시스템에 속한 열매나무가 등장한다.
  - 이런 소규모 몬스터 집단의 주변에 **보통 스폰된다**는 서술이 있다.
- **현재 반영**:
  - `ITM-002`는 열매 **효과의 월드별 선결정·외형 비신뢰성**은 이미 보존한다.
  - 열매나무의 몬스터 집단 인접 스폰 경향은 `ITM-007`로 승격됐다 (2026-08-20).
- **오너 확정 (2026-08-20)**: 스폰 경향을 일반 canon으로 승격 승인.
- **승격 범위**: **경향만**이다. 원문이 "보통"이라고만 하고 확률을 말하지 않으므로
  스폰 확률·집단 규모·거리 반경은 TBD로 남겼다. 역방향(몬스터 집단 → 반드시 열매나무)은
  근거가 없어 포함하지 않았다.
- **조치**: `ITM-007` 신설 완료.
- **추가 source 메모**:
  - 같은 캡처의 "보라색 열매가 이전 세계에서는 독이어도 이번 세계에서는 같다는 보장이 없음"은 `ITM-002`와 **MATCHED**.
  - 외형만 보고 효과를 확정할 수 없다는 뉘앙스도 `ITM-002`와 방향이 맞지만, **정확한 식별 수단(반드시 섭취해야 하는지, 감정/지식/실험이 가능한지)**은 별도 확정 전까지 만들지 않는다.
  - 장면 속 특정 사냥꾼의 독성 저항/레벨은 **SCENE-ONLY**.

## 다음 AI에게

1. `NSG-001/003/004/005/006/008`은 더 이상 미정이 아니다. **D-024와 연결된 Canon을 따른다.**
2. PHASE 3 함정 구현은 반드시 `FLR-028`을 읽고 **actor class가 아니라 trigger mechanism**을 모델링한다.
3. 2층+ 랜덤 인카운터는 `SYS-016`의 authored skeleton을 깨뜨리는 완전 즉흥 생성기로 만들지 않는다.
4. PHASE 7 NPC는 `NPC-006`의 경험/지식 상태와 `NPC-007`의 정보 비공개 원칙을 함께 따른다.
5. 언어 시스템/왕국 사회 설계 전 `WLD-011` 바벨탑을 확인하되 위치·외형·작동 원리는 TBD다.
6. **NSG-017은 해결됐다** (`D-025` → `ITM-007`, 오너 승인 2026-08-20). 다시 질문하지 않는다.
   다만 스폰 **확률·집단 규모·거리 반경은 여전히 TBD**이므로 구현 상수로 만들지 않는다.
7. 새 소설 발췌가 들어오면 `NSG-###` ID를 이어서 추가하고, SCENE-ONLY와 일반 규칙을 구분한다.

# SETTING_BIBLE — 세계관 Canon (v1.1)

이 위치에 **「탑 — 세계관·게임설정 통합본 v1.1」 원본**을 `SETTING_BIBLE_v1.1.docx`(또는 `.md`)로 넣는다.

이 문서가 세계관의 **진실(canon)**이며 `DECISIONS.md`와 함께 최우선 기준이다. 구현 편의를 이유로 조용히 바꾸지 않는다.

## 현재 상태 (2026-08-17)

| 파일 | 역할 |
| --- | --- |
| `SETTING_BIBLE_v1.1.docx` | **canon 원본 — 진실.** 충돌 시 항상 이긴다 |
| `SETTING_BIBLE_v1.1.md` | 자동 생성된 **참고 사본**. canon 아님. 직접 편집 금지 |

| `canon/INDEX.md` | ID가 붙은 검색용 색인 (137항목) |

## 마크다운 사본 규칙

오너 승인(2026-08-17)으로 마크다운 변환본을 함께 둔다.
**이유**: GitHub를 브라우징하는 AI 에이전트(GPT 등)가 docx 바이너리를 읽지 못해,
canon 원본을 못 보는 상태로 작업하게 되기 때문이다.

지켜야 할 것:

1. **`.md`를 직접 편집하지 않는다.** 자동 생성 파일이다.
   설정을 바꾸려면 **docx를 고치고 스크립트를 다시 돌린다.**
2. **docx가 개정되면 반드시 재생성한다.** 안 하면 사본이 낡은 canon을 퍼뜨린다.
   ```
   powershell -NoProfile -ExecutionPolicy Bypass -File tools/docx_to_md.ps1
   ```
   버전이 올라가면 경로를 넘긴다: `-DocxPath docs/SETTING_BIBLE_v1.2.docx`
3. **변환기는 스스로 검증한다.** 원본의 모든 문단이 출력물에 남아 있는지 확인하고,
   하나라도 빠지면 오류를 내며 중단한다(현재 666문단 / 누락 0).
   조용히 한 문단이 빠지면 그걸 읽는 에이전트는 "그런 규칙은 없다"고 판단해버리기 때문이다.
4. **사본과 원본이 다르면 원본을 따른다.** 예외 없다.

## 배치 방법

- 원본 docx는 Claude 프로젝트("탑 - 로그라이크 개발")에 보관돼 있던 것을 이 `docs/` 폴더에 복사해 커밋했다.
- `.gitattributes`에 `*.docx binary`가 설정돼 있어 git이 내용을 손상시키지 않는다.

## 왜 여기 두는가

협업 프로토콜상 GitHub 저장소가 코드의 단일 진실이고, 두 에이전트(설계/구현)는 대화가 아니라 저장소에서 컨텍스트를 복원한다. canon도 저장소에서 읽을 수 있어야 핸드오프가 깨지지 않는다.

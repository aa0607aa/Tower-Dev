# SETTING_BIBLE — 세계관 Canon (v1.1)

이 위치에 **「탑 — 세계관·게임설정 통합본 v1.1」 원본**을 `SETTING_BIBLE_v1.1.docx`(또는 `.md`)로 넣는다.

이 문서가 세계관의 **진실(canon)**이며 `DECISIONS.md`와 함께 최우선 기준이다. 구현 편의를 이유로 조용히 바꾸지 않는다.

## 배치 방법

- 원본 docx는 현재 Claude 프로젝트("탑 - 로그라이크 개발")에 보관되어 있다. 그 파일을 이 `docs/` 폴더에 복사해 커밋한다.
- git 기반 에이전트가 텍스트로 읽어야 하면, **오너 승인 하에** 마크다운 변환본(`SETTING_BIBLE_v1.1.md`)을 함께 둘 수 있다. 단, 변환 과정에서 canon 문구가 바뀌면 안 되므로 **docx 원본이 항상 우선**하며, 변환본과 원본이 다르면 원본을 따른다.

## 왜 여기 두는가

협업 프로토콜상 GitHub 저장소가 코드의 단일 진실이고, 두 에이전트(설계/구현)는 대화가 아니라 저장소에서 컨텍스트를 복원한다. canon도 저장소에서 읽을 수 있어야 핸드오프가 깨지지 않는다.

## 핵심 결과

### 실제 GAP/명시화 가치가 높은 항목

1. **NSG-003 — 함정의 외부 물체 발동 가능성**
   - 원작에서 돌을 던져 벽 화살 함정을 의도적으로 소모시킨다.
   - 현재 `FLR-011/012`에는 단서/1회 소모는 있으나 물체 trigger는 없다.
   - **PHASE 3 trap interaction 전에 오너 확인 권장.**

2. **NSG-001 — 랜덤 인카운터의 authored template + randomized details 구조**
   - `KGD-004`는 특정 팩션전 사례만 보존.
   - 일반적인 랜덤 인카운터 생성 원칙은 현재 색인에 없음.

3. **NSG-004 — 미궁 내 언어 통합**
   - 원작 발췌에는 명시되어 있으나 `SETTING_BIBLE/canon`에서 직접 대응 규칙을 찾지 못함.

4. **NSG-005 — NPC/생물의 경험 학습**
   - `NPC-001/003`은 지식/정보 전파를 보존하지만 경험에 따른 개별 행동 개선은 명시적이지 않음.

5. **NSG-008 — 왕국의 문에도 도달하지 못하는 유배자가 대다수**
   - 원작은 `70% 이상`으로 표현.
   - 현재 Canon은 "왕국 도달이 쉽지 않다"는 정성 표현만 있음.
   - 비율 자체를 하드 수치로 쓸지는 오너 결정 필요.

6. **NSG-006 — NPC 배경/능력의 전지적 UI 비공개, 대화·관찰 추론**
   - 현재 `SYS-005`와 방향은 맞지만 NPC UI 사례로 직접 명시되지 않음.

### 이미 반영된 항목

- 1층 고정 지형/고대 사원/심연/반복 학습
- 1시간 서든데스와 붕괴
- 인간 사냥과 뉴비 영입
- 1층 스폰 무기 품질 (`D-020`)
- 총기 극희귀
- 팩션전 결과가 계단 조건인 인카운터 (`KGD-004`)
- 정보/지식이 영구 성장이라는 철학

### 일반 Canon으로 확대하면 안 되는 장면

- 특정 3인조 살인 유배자
- 특정 회차의 계단 위치/계단 앞 두 사수
- 특정 샷건의 체감 가치
- 오르골의 97년 경험·심리 읽기·게임 지식

이들은 `SCENE-ONLY`로 분리했다.

## 근거

- 소설 원작 발췌는 현재 설정서보다 더 구체적인 사례를 제공하지만,
  **사례를 전체 세계 규칙으로 일반화하는 과정에는 오너 판단이 필요**하다.
- 따라서 감사 문서는 `MATCHED / PARTIAL / GAP / SCENE-ONLY`로 상태를 나누고
  `GAP`도 자동 Canon화하지 않는 구조로 작성했다.
- 특히 PHASE 3 함정 구현은 원작의 "돌로 화살 함정을 발동" 장면과 직접 맞닿아 있어
  구현 편의로 Player 전용 trigger를 굳히기 전에 확인할 필요가 있다.

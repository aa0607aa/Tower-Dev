# docs/log/ — 작업 로그 (월 단위)

> **새 세션을 시작하는 AI는 오늘 날짜에 해당하는 파일을 먼저 읽는다.**
> 예: 2026-08-18에 작업을 시작하면 `2026-08.md`를 읽는다.

## 왜 필요한가

`CURRENT_STATE.md`는 **지금 상태 하나**만 담는다. 최신 WORK REPORT로 계속 덮어쓰기 때문에
"어제 왜 그런 결정을 했는지", "직전 AI가 나에게 뭘 넘겼는지"는 남지 않는다.
`CHANGELOG.md`는 **확정된 변경**만 담아서 판단 과정이 없다.
`DECISIONS.md`는 **결정**만 담고 그 결정에 이르기까지의 작업은 없다.

그 사이에 구멍이 있다. **여러 AI가 서로의 기억을 공유하지 않는데, 판단 근거와 인계사항이
채팅에만 남는 것.** 협업 프로토콜 §3이 "대화 내용을 인수인계 수단으로 쓰면 반드시 망가진다"고
경고한 바로 그 지점이다.

이 폴더가 그 구멍을 메운다. **요청 → 작업 → 근거 → 인계**를 시각과 함께 시계열로 쌓는다.

## 다른 문서와의 관계

| 문서 | 담는 것 | 시간 |
| --- | --- | --- |
| `docs/log/YYYY-MM.md` | **요청·작업·근거·인계** | **시계열로 누적** |
| `CURRENT_STATE.md` | 지금 어디까지 왔나 | 최신본만 (덮어씀) |
| `CHANGELOG.md` | 확정된 변경 | 누적 (판단 없음) |
| `DECISIONS.md` | 확정된 결정 | 누적 (작업 과정 없음) |
| `docs/canon/` | 세계가 무엇인가 | 상태 (시간 없음) |

**중복이 아니다.** 같은 사건이 여러 문서에 나타나되 각자 다른 면을 담는다.
예를 들어 D-012(데이터 마이닝)는 — `DECISIONS.md`에 결정이, `docs/canon/SYS.md`에 규칙이,
`CHANGELOG.md`에 변경이, 그리고 **여기에 "오너가 어떻게 요청했고 왜 3단계로 쪼갰는지"**가 있다.

## 파일 규칙

- 한 달에 파일 하나: `2026-08.md`, `2026-09.md`
- 새 항목은 **파일 아래에 추가**한다 (시간 순, 오래된 것이 위)
- 월이 바뀌면 새 파일을 만들고, 이전 달의 **미완료 인계사항을 새 파일 맨 위로 옮긴다**

## 항목 형식

```markdown
## 2026-08-18 10:04 · <한 줄 제목>

**담당**: Claude (구현) / GPT (설계) / 오너

### 요청
> 오너의 요청. 요약하되, **정확한 문구가 판단에 영향을 주면 원문 그대로 인용한다.**
> 특히 설계 아이디어·수치·제약 조건은 원문을 남긴다.

### 작업
- 무엇을 했는가. 실행한 명령과 결과를 포함한다.

### 근거
- **왜 그렇게 했는가.** 다른 선택지가 있었다면 왜 그걸 안 골랐는가.
- 판단이 틀릴 수 있는 지점이면 그것도 적는다.

### 다음 AI에게
- [ ] 확인해야 할 것 / 이어서 할 것
- [ ] (완료되면 `[x]`로 바꾸고 어느 항목에서 처리했는지 적는다)

### 오너 결정 필요
- 없음 / <결정 요청 내용>  ← 있으면 **채팅으로도 직접 말한다**

**산출물**: 커밋 `해시` · 관련 문서
```

### 필드 규칙

| 필드 | 규칙 |
| --- | --- |
| **일시** | `YYYY-MM-DD HH:MM`. 커밋이 있으면 커밋 시각을 쓴다 |
| **담당** | 누가 했나. 세션 환경 기준(협업 프로토콜 §0) |
| **요청** | 요약 또는 원문 인용. **애매하면 원문을 남긴다** — 요약은 정보를 잃는다 |
| **작업** | 실행·검증 결과 포함. **실행 안 한 것을 했다고 쓰지 않는다** |
| **근거** | 판단의 이유. 이게 이 문서의 존재 이유다 |
| **다음 AI에게** | 체크박스. 다음 세션이 이것만 보고도 이어갈 수 있어야 한다 |
| **오너 결정 필요** | 있으면 채팅으로도 말한다. 문서에만 적고 넘어가지 않는다 |

## 지켜야 할 것

1. **작업이 끝날 때마다 쓴다.** 몰아서 쓰면 근거를 잊는다.
2. **근거를 빼먹지 않는다.** 결론만 있으면 다음 AI가 그걸 뒤집거나 잘못 확장한다.
3. **인계사항은 체크박스로.** 처리되면 `[x]`로 바꾸고 어느 항목에서 처리했는지 적는다.
4. **요청을 미화하지 않는다.** 오너가 지적한 것은 지적한 대로 적는다.
   실수를 지운 로그는 같은 실수를 반복시킨다.
5. **오너 결정이 필요하면 문서에만 적지 말고 채팅으로 직접 말한다.**

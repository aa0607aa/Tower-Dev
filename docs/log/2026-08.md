  테스트가 `AccessEnvelope`에 `record`/`has_mutation`이 **없음**을 단언한다 —
  있으면 언젠가 거기에 유배자별 복제본이 생긴다.
- **`to_sorted_records()`로 순회 순서를 고정했다.** Dictionary 순회 순서에 의존하면
  같은 상태가 다른 세이브를 만들어 `SYS-003` 결정성이 조용히 깨진다.
  삽입 순서가 달라도 같은 결과가 나오는지 테스트로 고정했다.
- `Rect2i`를 경계 정본으로 삼지 않았다 (`D-016` §1.5). 셀 집합 + 레이어 범위로 두어
  나중에 폴리곤·높이 밴드로 확장할 여지를 남겼다.

### 발견하고 고친 것 2건
1. **새 `class_name`이 임포트 전에는 전역 등록되지 않는다.** 테스트가 "not declared in the
   current scope"로 무더기 파스 에러를 냈다. → `run.ps1 -Mode test`가 `--import`를 먼저 하도록 수정.
2. **러너가 파스 에러에 죽었다.** `load()`가 인스턴스화 불가능한 스크립트를 돌려주는데
   `new()`를 불러 러너 자체가 중단되고 나머지 테스트가 실행되지 않았다.
   → `can_instantiate()` 확인 후 해당 파일만 실패 처리. 두 러너 모두 적용.

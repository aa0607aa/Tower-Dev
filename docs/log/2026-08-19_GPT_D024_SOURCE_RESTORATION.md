## 요청

오너가 `docs/reference/NOVEL_SOURCE_GAP_AUDIT.md`의 주요 GAP에 대해 다음과 같이 직접 확정했다.

1. **NSG-003** — 플레이어 외 물체도 실제 물리 메커니즘상 가능하면 함정을 트리거할 수 있다. 모든 물리 현상을 정상적으로 구현하는 방향.
2. **NSG-001** — 랜덤 인카운터는 저작된 기본 시나리오 골격을 가지고 세부만 랜덤화하는 철학이 맞다.
3. **NSG-004** — 미궁에서 언어가 통하며, 언어 통합 기능을 담당하는 구조물은 **「바벨탑」**이다.
4. **NSG-005** — NPC/생물 경험 학습 규칙이 빠져 있다면 추가한다.
5. **NSG-008** — 원작의 70%는 고정 수치가 아니라 일반 유배자의 수준과 난이도를 맞추는 기준감이다.
6. **NSG-006** — 과거 원본 게임의 전지적 UI보다 **소설 속 실제 세계를 구현**하는 방향. NPC 정보는 대화와 관찰로 알아낸다.

같은 요청에서 새 소설 캡처를 제공했다. 해당 발췌에는 시스템 열매나무, 열매 효과의 월드/회차별 변동,
외형만으로 효과를 알 수 없다는 묘사, 소규모 몬스터 집단 주변 열매나무 스폰 경향, 특정 사냥꾼의 독성 저항 장면이 있다.

- **WLD-011** — 바벨탑이 미궁의 언어를 통합한다.

### 3. 원작 GAP 장부 갱신

`docs/reference/NOVEL_SOURCE_GAP_AUDIT.md`에서

새 캡처는 다음처럼 판정했다.

- 열매 효과가 월드/회차마다 다를 수 있고 같은 색·외형이 같은 효과를 보장하지 않는다는 핵심은 **`ITM-002`와 MATCHED**.
- **NSG-017 신규 GAP** — 시스템 열매나무가 소규모 몬스터 집단 주변에 자주 스폰되는 경향.
  오너가 이번 메시지에서 이 스폰 경향 자체를 일반 Canon으로 확정하지 않았으므로 자동 승격하지 않았다.
- "먹기 전에는 알 방법이 없다"는 원작 표현은 외형 비신뢰성의 강한 source지만,
  감정/실험/지식 등 다른 식별 수단까지 영구 금지하는 규칙으로는 아직 확대하지 않는다.
- 장면 속 특정 사냥꾼의 독성 저항/레벨은 **SCENE-ONLY**.

# STYLE_GUIDE.md — 「탑」 도트 아트 규칙

> **현재 상태: 골격만 있음.** 실제 팔레트·외곽선·광원 규칙은 PHASE 8(도트 아트 1차)에서 확정한다.
> PHASE 0~7은 임시 도형/색 박스로 진행한다. 아래 [TBD]를 지금 임의로 채우지 않는다.

## 확정된 것 (개발 가이드 §9 — DESIGN, 튜닝 가능)

| 항목 | 값 |
| --- | --- |
| 맵 타일 | **32×32** |
| 캐릭터 스프라이트 | 48×48 / 64×64 프로토타입 비교 후 **하나로 고정** — 미정 |
| pivot | 타일 중심 **하단** 통일 |
| 아이템 아이콘 | 16×16 또는 24×24 |
| UI 아이콘 | 24×24 또는 32×32 |
| 보스 | 다중 타일 허용 |
| 텍스처 필터 | **nearest** (project.godot 전역 설정) |
| 시점 | 2D 탑다운 / 쿼터뷰 |

## 첫 애니메이션 세트

Idle 4 / Walk 6~8 / Run 6~8 / Attack 4~8 / Hit 2~3 / Death 6~10 프레임.

## 원칙

- 첫 단계는 화려함보다 **실루엣·판독성** 우선. 기본 비율을 확정한 뒤 종족/NPC 변형으로 넘어간다.
- **함정 단서는 도트로 읽혀야 한다.** 치명 함정의 단서가 화면에서 안 보이면 그건 아트 버그가 아니라
  **canon 위반**이다 (모든 치명 함정에 사전 단서 필수). 이 항목은 반드시 PLAYTESTED가 필요하다.
- 특수 시설(계단/생명의 샘/모루)은 NPC 시점에서 투명 처리되지만 **플레이어에게는 명확히 보여야** 한다.
- AI 이미지 생성은 컨셉/기준안에만 쓴다. 실제 스프라이트 시트는 동일 캐릭터·프레임 일관성 검수를
  통과해야 반입한다.
